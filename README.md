# ExotiCare

ExotiCare is a mobile application for managing exotic pets 
and a shop selling accessories for the care of exotic animals,
developed as an engineering thesis project.

## Technologies

- Flutter
- Dart
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

## Features

- User registration and login
- Animal management
- Feeding schedule
- Care reminders
- User profile
- Browsing the store
- Adding products to cart or favorites
- Paying for products

## Project structure

```
ExotiCare/
├── ExotiCareApi/
└── ExotiCareApp/
```
